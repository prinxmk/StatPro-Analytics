# Phase 1J — v1.3.0

This release batches the next four roadmap areas for one test cycle.

## v1.0 Regression prediction
- Existing-observation fitted values and residuals.
- 95% confidence intervals for the fitted mean response.
- 95% prediction intervals for individual responses.
- Regression summary and complete-case accounting.

## v1.1 Binary logistic regression
- Binary 0/1 outcomes (plus common textual binary labels).
- Multiple numeric predictors.
- Maximum-likelihood Newton iterations.
- Coefficients, robust numerical safeguards, odds ratios, 95% OR intervals, z tests.
- Log likelihood, -2LL, AIC, BIC, McFadden R² and classification metrics.

## v1.2 Time series
- Time/order field plus numeric series.
- Lag 1, first difference, percent change, moving average.
- Trend slope/R² and lag-1 autocorrelation.
- Current row order is preserved; no automatic date sorting.

## v1.3 Econometrics
- OLS with HC1 heteroskedasticity-consistent standard errors.
- Breusch–Pagan heteroskedasticity test.
- Durbin–Watson and model fit statistics.
- Augmented Dickey–Fuller/DF unit-root test with zero augmentation lags and approximate critical values.
